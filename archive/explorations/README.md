# Explorations

Snapshots of design directions explored for Projector that didn't make the cut, kept here as reference. Folded in from the now-archived `projectionist-explorations` repo (itself a holdover from the pre-rename "Playback Room" / "Selekt" naming).

## Corner-scallop curtain motif

`index.html` — a variant of the design language where every live/paused screen carried a soft oxblood scallop bled into both top corners (plus a `)( ` typographic glyph joining film title to timecode, later dropped). Ultimately deemed too busy for the resting matte identity the rest of the system holds to. See `DESIGN.md` for the full writeup of what was tried and why.
